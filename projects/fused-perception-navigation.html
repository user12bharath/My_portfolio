Fused Perception-Navigation Autonomous Robot

  • Tech Stack: ROS2 Jazzy, Gazebo Harmonic, Nav2, AMCL, YOLOv8n, LiDAR, twist_mux, URDF/Xacro
  • Github URL: Project Link

Built a full autonomous robot stack with SLAM mapping, AMCL localization, Nav2 planning, and real-time object-aware safety behavior.

The system fuses YOLOv8n object confirmation with LiDAR range data, using priority arbitration through twist_mux so navigation can continue normally while safety overrides can stop the robot reactively.

Replaced an initial HSV-threshold detector with a decoupled YOLOv8n ROS2 interface, allowing the perception module to improve without changing downstream control nodes.
